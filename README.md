StepUp – Premium Sneaker Store 👟

Proje Hakkında



StepUp, modern ve premium bir sneaker satış deneyimi sunmak için geliştirilmiş şık ve tamamen responsive bir e-ticaret arayüzüdür.

Bootstrap 5, modern CSS animasyonları ve JavaScript kullanılarak geliştirilmiştir.



Kullanıcı dostu tasarımı, dinamik animasyonları, tema sistemi ve localStorage tabanlı sepet / kullanıcı yönetimi ile güçlü bir frontend deneyimi sağlar.
